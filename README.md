# 焦虑自测量表程序

一个基于 GAD-7（广泛性焦虑障碍量表）的焦虑自测评估工具。

## 功能特点

- **标准化评估**：采用国际通用的 GAD-7 量表
- **交互式测量**：7 个问题，4 个评分选项
- **自动评分**：根据答案自动计算总分并生成评估结果
- **分级诊断**：将焦虑程度分为 4 个级别
- **详细报告**：展示每个问题的答案和总体评估结果

## GAD-7 量表说明

GAD-7 是一个被广泛使用的焦虑症筛查工具，包含 7 个问题，评估过去两周内的焦虑症状。

### 评分标准

每个问题有 4 个选项：
- 0 分：完全不会
- 1 分：几天
- 2 分：一半以上的天数
- 3 分：几乎每天

### 结果解读

总分范围：0-21 分

- **0-4 分**：轻微焦虑 - 属于正常范围
- **5-9 分**：轻度焦虑 - 建议保持良好的生活习惯
- **10-14 分**：中度焦虑 - 建议寻求心理咨询
- **15-21 分**：重度焦虑 - 强烈建议寻求专业帮助

## 使用方法

### 运行程序

```bash
python3 anxiety_assessment.py
```

### 使用步骤

1. 运行程序后，阅读欢迎信息和选项说明
2. 逐个回答 7 个问题，每个问题输入 0-3 之间的数字
3. 完成所有问题后，程序会自动计算总分并显示评估结果
4. 查看详细的答案回顾和建议

### 示例交互

```
============================================================
                   焦虑自测量表 (GAD-7)
============================================================

说明：请回忆过去两周内，您被以下问题困扰的频率。
每个问题请选择最符合您情况的选项（输入对应数字）。

选项说明：
  0 - 完全不会
  1 - 几天
  2 - 一半以上的天数
  3 - 几乎每天

------------------------------------------------------------
开始测评：

问题 1/7：感觉紧张、焦虑或急切
请输入您的选择 (0-3): 1

问题 2/7：不能够停止或控制担忧
请输入您的选择 (0-3): 0

...
```

## 运行测试

程序包含自动测试脚本，可以测试不同焦虑级别的评估结果：

```bash
python3 test_anxiety_assessment.py
```

测试脚本会运行 4 个测试案例，分别对应：
- 轻微焦虑（总分 3）
- 轻度焦虑（总分 7）
- 中度焦虑（总分 12）
- 重度焦虑（总分 18）

## 重要提示

本测评工具仅供自我筛查和参考使用，不能替代专业的医疗诊断。如果您：

- 感到严重的焦虑或恐慌
- 有自杀或自伤的想法
- 焦虑症状严重影响日常生活

请立即寻求专业心理咨询师或精神科医生的帮助。

本项目仅用于教育和自我评估目的。
