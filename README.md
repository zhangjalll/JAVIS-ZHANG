# 1. 焦虑自测量表程序

一个基于 GAD-7（广泛性焦虑障碍量表）的焦虑自测评估工具。

## 功能特点

- **标准化评估**：采用国际通用的 GAD-7 量表
- **交互式测量**：7 个问题，4 个评分选项
- **自动评分**：根据答案自动计算总分并生成评估结果
- **分级诊断**：将焦虑程度分为 4 个级别
- **详细报告**：展示每个问题的答案和总体评估结果

## GAD-7 量表说明

GAD-7 是一个被广泛使用的焦虑症筛查工具，包含 7 个问题，评估过去两周内的焦虑症状。

### 评分标准

每个问题有 4 个选项：
- 0 分：完全不会
- 1 分：几天
- 2 分：一半以上的天数
- 3 分：几乎每天

### 结果解读

总分范围：0-21 分

- **0-4 分**：轻微焦虑 - 属于正常范围
- **5-9 分**：轻度焦虑 - 建议保持良好的生活习惯
- **10-14 分**：中度焦虑 - 建议寻求心理咨询
- **15-21 分**：重度焦虑 - 强烈建议寻求专业帮助

## 使用方法

### 运行程序

```bash
python3 anxiety_assessment.py
```

### 使用步骤

1. 运行程序后，阅读欢迎信息和选项说明
2. 逐个回答 7 个问题，每个问题输入 0-3 之间的数字
3. 完成所有问题后，程序会自动计算总分并显示评估结果
4. 查看详细的答案回顾和建议

# 2. AI中医心血管问诊系统

一个基于规则的智能中医心血管问诊对话系统，采用中医辨证理论进行证型分析。

## 功能特点

- **智能问诊**：分层采集症状，根据主诉动态调整询问内容
- **辨证分析**：涵盖5种常见心血管证型的辨证匹配
- **四诊合参**：综合症状、舌象、脉象、面色等中医信息
- **个性化建议**：提供食疗、穴位保健、生活调理方案
- **规则引擎**：基于症状权重的多证型匹配算法

## 支持的证型

系统可识别以下5种中医心血管证型：

| 证型 | 核心表现 | 治则 |
|------|---------|------|
| **心气虚证** | 心悸、气短、乏力，活动后加重 | 益气养心 |
| **心阳虚证** | 畏寒肢冷、面色苍白、舌淡胖 | 温补心阳 |
| **心血瘀阻证** | 胸痛刺痛、夜间加重、舌紫暗 | 活血化瘀 |
| **痰浊内阻证** | 胸闷、痰多、体型肥胖、苔厚腻 | 化痰降浊 |
| **气阴两虚证** | 心悸、口干、五心烦热、盗汗 | 益气养阴 |

## 问诊流程

```
【第一步：主要症状】
  ↓ 收集主诉（胸痛、心悸、气短等）
  ↓ 针对胸痛进行详细分支询问

【第二步：伴随症状】
  ↓ 畏寒怕冷、出汗、失眠等

【第三步：中医体征】
  ↓ 舌象（舌色、舌形、舌苔）
  ↓ 脉象（自测脉搏特征）
  ↓ 面色、体型

【智能分析】
  ↓ 症状权重评分
  ↓ 多证型匹配算法
  ↓ 主证型 + 兼夹证识别

【结果报告】
  ↓ 辨证结论
  ↓ 食疗建议
  ↓ 穴位保健
  ↓ 生活调理
```

## 技术架构

### 核心算法

**症状权重评分系统**
```python
# 每个证型定义症状权重（1-3分）
weight = {
    '主要症状': 3,      # 高权重
    '次要症状': 2,      # 中权重
    '一般症状': 1       # 低权重
}
```

**多证型匹配**
- 计算所有证型的症状匹配得分
- 按得分排序，得分最高为主证型
- 得分≥主证型50%者为兼夹证

### 知识库结构

```
证型知识库
├── 心气虚证
│   ├── 主要症状
│   ├── 次要症状
│   ├── 舌脉特征
│   ├── 症状权重
│   └── 调理建议
├── 心阳虚证
├── 心血瘀阻证
├── 痰浊内阻证
└── 气阴两虚证
```

## 重要提示

⚠️ **本系统的局限性**

1. **不能替代医师诊断**
   - 中医诊断需要专业医师四诊合参
   - 舌脉等体征需要丰富的临床经验判断

2. **适用场景**
   - ✅ 健康科普和中医知识学习
   - ✅ 了解中医辨证思路
   - ✅ 日常保健参考
   - ❌ 不能用于疾病诊断
   - ❌ 不能替代就医

   - 剧烈胸痛持续不缓解

   - 晕厥或意识丧失
   - 心悸严重影响日常生活

4. **用药需在医师指导下进行**
   - 本系统仅提供食疗和穴位建议
   - 任何中药使用必须咨询专业中医师
